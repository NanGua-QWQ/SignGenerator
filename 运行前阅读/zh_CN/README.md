# 道路标牌生成器使用教程

简体中文 · 离线精简版 · 更新日期：2026-09-06

[English guide](../en_US/README.md)

本程序用于在浏览器中制作道路名称、交叉路口、地点距离、立交枢纽、出入口和自由排版标牌，并导出 SVG 矢量图。程序包含 **6 个工作区、18 种新增模板**，字体与运行文件均随程序提供。

**日常使用只需要双击程序根目录的“一键启动.bat”。不需要重新构建，也不需要安装开发依赖。**

## 1. 全新电脑需要准备什么

### 1.1 准备完整程序文件夹

将完整的 `SignGenerator` 文件夹复制到电脑本地。如果收到的是压缩包，请先全部解压，再运行里面的文件，不要直接在压缩包预览窗口中启动。

文件夹可以放在其他盘符或位置，不必与原电脑一样使用 F 盘。例如，`D:\SignGenerator` 也可以。复制后不要单独移动启动脚本，也不要在程序运行期间移动文件夹。

正常运行至少要保留同一目录下的：

```text
SignGenerator/
├─ 一键启动.bat
├─ server.mjs
└─ out/                 ← 已生成的页面、程序和字体，必须完整保留
```

建议直接保留整套文件，包括源码、构建脚本和教程，方便以后维护。

### 1.2 准备 Windows 与浏览器

- 使用可安装所选 Node.js 版本的 Windows 电脑；本项目的一键脚本面向 Windows 10/11。
- 准备现代浏览器，优先使用电脑已有的 Microsoft Edge，也可使用 Chrome 等。
- 小屏幕下设置面板可能显示在预览下方；桌面使用时建议最大化浏览器窗口。

### 1.3 安装 Node.js：通常只需做一次

Node.js 是启动本地程序的运行环境。**它不是本程序的编辑器，也不需要你学习编程。**

1. 打开 [Node.js 官方下载页面](https://nodejs.org/en/download)。
2. 选择 **LTS（长期支持版）**，操作系统选 **Windows**，下载 **Windows Installer（`.msi`）**。优先安装仍受官方支持的 LTS 版本。
3. 架构按电脑选择：多数 Intel/AMD 电脑使用 **x64**；Windows ARM 电脑使用 **ARM64**。不确定时，在 Windows“设置 → 系统 → 关于”中查看“系统类型”。
4. 打开安装包，按安装向导完成安装。保留默认的 Node.js、npm 和 PATH 环境变量相关选项；如果出现额外的原生模块编译工具安装选项，日常运行本程序不需要安装那些额外工具。
5. 安装后关闭旧的启动窗口，再重新双击“一键启动.bat”，让它识别新安装的环境。

本程序启动脚本要求 **Node.js 20.9 或更高版本**；这是最低版本检查，不代表应优先安装已经停止支持的旧版本。新电脑请以官网仍受支持的 LTS 版本为准。

如果电脑已经安装了合适版本的 Node.js，可以跳过安装。想核对版本时，可在终端输入 `node --version`，例如显示 `v24.x.x`。

### 1.4 哪些东西不用装

日常运行不需要安装 pnpm、代码编辑器、Python、数据库、单独的交通标志字体，或 `node_modules` 开发依赖。也不需要先双击“重新构建.bat”。

下载 Node.js 安装包时需要联网；完整安装运行环境并复制完整程序后，正常启动、编辑和 SVG 导出可以离线进行。如果目标电脑没有网络，可以先在其他电脑从官网下载匹配的安装包，再复制过去安装。

## 2. 启动关闭与日常使用

### 启动

1. 返回程序根目录，即能看到 `一键启动.bat` 的 `SignGenerator` 文件夹。
2. 双击 **一键启动.bat**。
3. 出现 `Road Sign Generator is ready` 后，说明本地服务已启动。
4. 浏览器通常会自动打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。如果没有自动打开，自己在地址栏输入该地址即可。

这里的 `127.0.0.1` 指当前电脑，程序运行在本地，不是要连接外部网站。不要直接双击 `out/index.html` 来代替启动脚本。

### 使用期间

保留启动时出现的命令行窗口，可以将它最小化。页面中的标牌在浏览器里编辑，启动窗口负责提供页面和字体文件。

一个启动窗口即可。需要继续使用时先检查原来的窗口是否还在运行，不要反复双击启动多个服务。

### 关闭

完成编辑后，可关闭启动窗口停止程序；也可在该窗口按 `Ctrl+C`，如果出现确认提示，按提示结束。只关闭浏览器标签页不会自动停止后台服务。

再次双击“一键启动.bat”，并使用原来的浏览器、用户配置和地址，即可继续读取已保存的内容。

## 3. 五分钟制作第一块标牌

以制作“沈海高速 G15”编号牌为例：

1. 在顶部选择 **道路名称标识**。
2. 点击左侧列表标题旁的 **＋**，选择 **高速道路名称标识**。
3. 在右侧“高速类型”选择 **国家高速**。
4. 在“道路编号”中输入 `15`。此处只填数字，程序会按道路类型处理前缀。
5. 在“高速名称”中输入 `沈海高速`。
6. 检查中间预览，使用放大、缩小和复位按钮查看效果。
7. 点击预览工具栏中的 **下载 SVG** 按钮。
8. 在浏览器设置的下载文件夹中找到 `.svg` 文件，并用浏览器打开检查。

编辑后页面会自动保存工作区，不需要寻找“保存”按钮。**自动保存编辑内容与下载 SVG 是两件不同的事**，建议成品同时导出留档。

## 4. 界面与通用操作

| 区域 | 作用 |
| --- | --- |
| 顶部工作区标签 | 在六类标牌之间切换 |
| 顶部太阳/月亮按钮 | 切换浅色与深色主题；不改变标牌本身的底色 |
| 左侧标牌列表 | 新增、选择、排序、快捷编辑和删除标牌 |
| 中间预览区 | 实时显示当前标牌，提供缩放、复位和下载 |
| 右侧设置区 | 修改当前模板支持的文字、编号、方向、距离、颜色和版式 |

较窄的窗口会调整布局，设置区可能移到预览下方。部分面板需要单独滚动。

### 列表管理

- **新增**：点击列表右上角 `＋`，再选择模板。各工作区的新增菜单不同。
- **选择**：点击列表中的标牌项，右侧设置与中间预览会切换到该项。
- **排序**：按住标牌项左侧的点状拖动手柄，拖到目标项前后。
- **快捷编辑**：右键单击标牌项，可修改列表选项名称和列表配色；还可打开较大的编辑对话框。列表配色与标牌底色是不同设置。
- **删除**：点击该项的垃圾桶按钮，在确认框中选择“删除”；“取消”会保留原项。程序会保留每种模板的最后一个标牌，因此某些仅剩一项的模板不会被真正删空。

### 预览操作

| 操作 | 方法 |
| --- | --- |
| 放大/缩小 | 点击预览工具栏的对应放大镜按钮 |
| 滚轮缩放 | 鼠标放在画布内，按住 `Ctrl` 滚动滚轮 |
| 平移 | 在预览画布内按住鼠标左键拖动 |
| 复位 | 点击回转箭头，恢复 100% 和初始位置 |
| 下载 | 点击“下载 SVG”按钮，导出当前选中的标牌 |

缩放范围为 40%～300%。画布缩放和平移只影响查看位置，不会改变导出 SVG 的矢量尺寸或画质。

## 5. 六个工作区与全部模板

可用设置会随模板改变。下文列出主要用途，具体字段、字数限制和可选项以当前右侧面板为准。

### 5.1 道路名称标识：4 种模板

| 新增菜单 | 主要功能 |
| --- | --- |
| 高速道路名称标识 | 国家高速、省高速、京津冀高速；编号、路名、省份简称及部分编号排版选项 |
| 城市道路名称标识 | 城市道路名称、标志样式，以及适用样式中的道路编号牌引用 |
| 无编号快速路道路标识 | 不带编号的快速路路名标识，长路名自动调整排版 |
| 普通道路名称标识 | 国道、省道、县道、乡道，分别对应 G、S、X、Y 前缀 |

高速编号输入支持 1～4 位数字。高速名称可以留空，以生成不含路名的编号牌。其他字段按界面提示填写。

如果后面要在路口、距离牌或出入口标牌里引用道路编号，建议先在这里创建对应的道路名称标识。

### 5.2 交叉路口：2 种模板

**交叉路口指路标志**：设置交叉道路名称、左上角方位，并分别配置不同方向的信息。每个方向最多 5 行，可填写道路名称或选择已有道路编号牌；不需要的行可单独删除。

**环岛图形式**：选择方形或横向版面，决定是否显示地理方向，设置当前驶入道路等级，并启用需要的环岛出口。各出口可配置目的地、道路编号和道路等级；不同道路等级使用不同粗细的线条，最多可启用 5 个出口。

### 5.3 地点距离标识：1 种模板

选择绿色、蓝色或棕色底色，添加目的地信息行。每行可使用地点文字或已有道路标识，设置英文行、距离和单位，也可删除不需要的行。

英文内容需要手动填写，程序不会自动翻译中文。距离单位请在对应选项中选择，不要把数字和单位随意混填到同一个字段。

### 5.4 立交枢纽指引：5 种模板

| 新增菜单 | 主要用途 |
| --- | --- |
| 分向指路标志 | 配置不同方向的道路编号和目的地 |
| 道路分岔预告 | 配置左右分岔方向、路线、出口信息和预告距离 |
| 2车道立交枢纽出口 | 表现双车道出口的道路与目的地指引 |
| 双出口枢纽式互通立体交叉出口预告 | 配置上下两组高速编号、目的地和距离 |
| 双向出口预告 | 配置出口编号及左右两个方向的道路、方位和目的地 |

可以在相关下拉菜单中引用已有道路标识。修改被引用的道路时，依赖该道路的预览可能随之更新，请同步检查相关成品。

### 5.5 出入口指引：5 种模板

| 新增菜单 | 主要功能 |
| --- | --- |
| 国标出口标识 | 出口编号、道路编号、目的地和出口方向 |
| 普通道路出口 | 道路名称或道路标识内容，支持适用的底色和出口方向 |
| 无编号城市快速路出口预告 | 道路名称、方位、目标道路和出口箭头 |
| 无编号城市快速路入口预告 | 道路名称、两个目的地和入口距离 |
| 入口预告-2方向 | 高速编号、方位角标、方向内容、入口方向，以及距离显示与单位等选项 |

部分内容可以通过勾选项显示或隐藏。字段暂时消失时，先检查该功能是否关闭或模板是否已切换。

### 5.6 自由模式：1 种模板，多种版式

点击 `＋` 后选择 **自由标志**。这个模板适合将文字、道路标识与箭头自由组合。

- 选择自由模式、左出口、右出口、直行或车道指引等版式。
- 选择绿色、蓝色或棕色背景，并调整不透明度。
- 按需显示出口编号牌、字母编号、自定义出口名称、出口距离及顶部信息栏。
- 正文最多 5 行；可添加、复制、移动或删除行，并设置适用的分割线。
- 每行可添加多个元素；元素可为文字、道路标识或箭头，并可复制、左右移动和删除。
- 文字可增加手动填写的英文行，以及前缀/后缀图标；道路标识可引用已有标牌并设置方位。

建议先确定版式与底色，再设置出口信息，最后逐行添加内容。按钮变灰时，通常表示已达到数量上限、已经位于边界位置，或至少需要保留一个内容项。

## 6. 导出字体与文件使用

- 当前界面提供 **SVG 导出**，不是 PNG、JPEG、PDF 或整个工作区工程文件。
- 一次下载的是当前选中的一块标牌；如需多块，请逐个选择并下载。
- SVG 文件保存在浏览器指定的下载目录中，该目录不一定与程序文件夹相同。同名文件可能被浏览器自动加上序号。
- 文字在生成时转换为矢量路径，因此查看成品通常不需要另外安装交通字体；在矢量编辑器中，这些字形通常作为路径而不是可直接输入修改的文字。
- SVG 可用浏览器查看，也可交给支持 SVG 的矢量图形软件继续处理。需要其他格式时，在支持该格式的软件中另行转换。
- 放大镜不会提升或降低导出质量，SVG 本身是矢量格式。

## 7. 自动保存备份与换电脑

### 自动保存在哪里

编辑内容自动保存在**当前电脑、当前浏览器、当前用户配置、当前站点地址**的本地存储中。程序没有云端账号或自动云同步。

`http://127.0.0.1:3000` 与 `http://localhost:3000`、不同端口、Edge 与 Chrome、不同浏览器用户配置，可能对应不同的存储空间。日常请固定使用同一浏览器和同一地址。

### 哪些操作可能影响记录

清除该站点数据、重置或删除浏览器用户配置、使用无痕模式，都可能使记录无法保留或恢复。删除标牌也没有通用的撤销/回收站功能。

### 怎么备份和迁移

1. 重要成品逐一下载为 SVG，另存到自己的备份目录。
2. 程序文件夹可以整套复制到新电脑；新电脑按第 1 节安装 Node.js 后即可启动。
3. **复制程序文件夹不会带走旧电脑浏览器里的编辑记录。**
4. 当前界面没有整个工作区的导入/导出功能，也没有将 SVG 导回为可继续编辑的标牌配置的功能。SVG 是成品备份，不能替代可编辑工作区备份。
5. 如果必须迁移可继续编辑的历史记录，请先保留旧电脑的浏览器数据，在清除或更换环境前安排浏览器本地数据的专门备份。

## 8. 一键启动与重新构建的区别

| 你要做的事 | 使用哪个入口 |
| --- | --- |
| 打开程序、制作标牌、改文字、导出 SVG | **一键启动.bat** |
| 把完整程序复制到另一台电脑后使用 | 安装 Node.js，然后 **一键启动.bat** |
| 修改程序源码、界面或功能后让修改生效 | **重新构建.bat** |
| `out` 丢失，需要从完整源码恢复运行文件 | **重新构建.bat**，或重新复制完整程序 |

“重新构建”会临时安装开发依赖，执行代码检查、生成离线版本并验证本地服务。成功后自动清理开发依赖和构建缓存，使文件夹回到精简状态。它通常需要联网，也需要额外的临时磁盘空间；依赖和构建文件可能占用数百 MB，请预留足够空间。

操作前关闭正在运行的程序，双击“重新构建.bat”，等待完成，再用“一键启动.bat”打开。构建失败时先阅读错误信息，不要把未完成的输出当作可用版本。

重新构建不是重置操作，不会主动清空浏览器里的标牌记录。**教程文件的修改也不需要重新构建。**

精简版没有 `node_modules`、`.next` 或 `.next-webpack` 是正常情况。不要为了“补全目录”而自行安装依赖；日常运行不需要它们。

## 10. 常见问题

### 提示 Node.js was not found

安装 Node.js，并确保安装时保留 PATH 相关选项。安装完成后关闭旧启动窗口，重新运行脚本。若仍无法识别，可重新登录 Windows 后再试。

### 提示 Node.js 20.9 or later is required

现有 Node.js 太旧。安装官网仍受支持且满足最低要求的 LTS 版本，再重新启动。

### 提示 offline build is missing

`out` 缺失或不完整。优先重新复制完整程序；如果完整源码还在，也可运行“重新构建.bat”。仅复制启动脚本不能恢复运行文件。

### 提示 Port 3000 is already in use

先访问 `http://127.0.0.1:3000`，确认是否已有本程序运行。如果是，直接使用原页面即可；否则关闭自己先前启动的服务，或查明占用端口的程序。不要为了避开冲突随意换端口，否则会进入另一份浏览器存储空间。

### 浏览器没有自动打开

确认启动窗口已出现 `is ready`，再手动输入 `http://127.0.0.1:3000`。如果显示无法连接，检查启动窗口是否仍开着，或是否已经输出错误。

### 页面空白、字体不显示或修改后仍是旧界面

确认是通过本地网址打开，而不是 `file://` 文件。核对 `out` 是否完整；关闭旧服务并重新启动，再按 `Ctrl+F5` 强制刷新页面。修改了源码但没有重新构建时，离线版仍会运行旧版本。不要把“清除站点数据”作为首选排查方式，以免丢失标牌记录。

### 原来的标牌不见了

检查浏览器、用户配置和地址是否与原来相同，是否进入无痕模式，是否清理过站点数据。程序文件还在不代表浏览器编辑记录也还在；请先回到原来的使用环境查找。

### 下载后找不到文件

查看浏览器设置的下载目录和下载状态，确认文件扩展名是 `.svg`。如果浏览器提示下载未完成或被阻止，按浏览器提示检查该文件和下载设置。

### 无法添加、删除或输入更多内容

先检查是否达到行数、元素数或字数限制，是否只剩最后一个同类模板/内容项。控件可能因当前模板或勾选项而隐藏或禁用；以面板提示为准。

### 引用道路的下拉列表没有需要的编号

先到“道路名称标识”创建对应道路，再回到目标工作区选择引用。不同模板只显示适用的道路类型。

### 重新构建失败后文件夹变大

开发依赖和缓存会在构建过程中临时生成，只有成功完成整套构建与检查后才会自动清理。先处理错误并重新构建，不要在构建过程中手动删除文件。

## 11. 高级辅助工具与开发命令

### 坐标与测量辅助（可选）

普通制作不需要这一节。当前程序还包含两个开发辅助开关，可在本页面的浏览器开发者工具控制台中输入：

```javascript
window.position
```

这会切换画布坐标显示；再次输入则关闭。鼠标位于画布时会显示对应位置。

```javascript
window.px
```

这会切换测量模式。在画布上拖动两点可查看横向、纵向及直线距离；按住 `Shift` 可约束为水平或垂直测量。测量模式开启时拖动用于测量，再次输入 `window.px` 关闭后恢复普通拖动。数值是标牌内部 SVG 坐标单位，不等于实物毫米尺寸。

### 开发者命令（可选）

在程序根目录执行；普通用户无需运行这些命令。

```powershell
# 已构建版本：不依赖 pnpm 或 node_modules
node server.mjs

# 验证离线服务：需保留 out、src 和 tests
node --test tests/server.test.mjs

# 开发模式：需先安装 pnpm，并安装项目依赖
pnpm install --frozen-lockfile
pnpm dev

# 检查代码和生成离线文件
pnpm lint
pnpm build
```

手动执行开发或构建命令会产生依赖与缓存；如需构建后自动恢复精简状态，使用根目录的“重新构建.bat”。

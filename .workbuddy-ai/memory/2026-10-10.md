## 2. 快捷键系统 + 撤销/重做

### 历史栈的实现方式（重要）
`studio-store.ts` 里把 `layoutProjectAtom` 从 **primitive 改成派生 atom**：

```ts
const baseProjectAtom = atom<LayoutProject>(createLayoutProject())   // 真实存储，不导出
const historyAtom = atom<HistoryState>({ past: [], future: [], lastAt: 0 })

export const layoutProjectAtom = atom(
  get => get(baseProjectAtom),
  (get, set, next) => { /* 记一步历史（450ms 窗口内合并）后 set(base) */ },
)
```

好处：store 里所有 `set(layoutProjectAtom, next)` **自动获得撤销能力**，
不用给每个写 atom 各写一遍。读路径（`useAtomValue` / `get`）完全不受影响。

- `HISTORY_LIMIT = 80`；`COALESCE_MS = 450` —— 拖拽/连按方向键合并成一步撤销。
- `replaceProjectAtom`：整份替换（新建/读档/导入），**清空**撤销栈。
  `setLayoutProjectAtom` / `resetLayoutProjectAtom` / `setSignSizeAtom(reset:true)` 都改走它。
- `undoAtom` / `redoAtom` 直接 `set(baseProjectAtom, …)`（绕过历史），并修正失效的选中项。
- 剪贴板 `clipboardAtom`（内存，不入存档）+ `copyElementAtom` / `pasteElementAtom`（粘贴右下偏 2 bit）。
- `recenterAtom`（自增 token）→ `DesignCanvas` 的 `recenterToken` prop → `setOffset({0,0})`。
- `DEFAULT_ZOOM = 14` 导出，`canvasViewAtom` 与快捷键 0 共用。
- `ZOOM_STEPS` 从 `DesignCanvas` **导出**，`page.tsx` 按档位缩放复用。

### 快捷键表（分发在 `page.tsx`，对照表在 `studio/ShortcutHelpDialog.tsx`）
| 键 | 作用 |
| --- | --- |
| ↑↓←→ / Shift+↑↓←→ | 微调 1 bit / 8 bit |
| Delete / Backspace | 删除选中 |
| Ctrl+D | 原位复制 |
| Ctrl+C / Ctrl+V | 复制 / 粘贴 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| ] / [ | 上移 / 下移一层 |
| R / Shift+R | 旋转 ±15°（文本 rotZ，贴图 rotX） |
| V | 显示/隐藏选中 |
| G | 网格开关 |
| + / - | 缩放画布 |
| 0 | 回到中心 + 恢复默认缩放 |
| Esc | 取消选择 |
| 空格+拖 / Alt+拖 | 平移 / 忽略吸附（原有） |

⚠️ **踩坑**：最初把 `if (mod) return` 放在 Ctrl+C/D 之前，导致 **Ctrl+C 永远走不到**。
正确顺序：先处理全局 mod 键（Z/Y/V）→ 非 mod 的视图键 → 选中相关键（Delete/D/C）→
最后 `if (mod) return` 把剩余 Ctrl 组合交还浏览器。

⚠️ **踩坑**：`ShortcutHelpDialog` 的 Esc 用 `stopImmediatePropagation()`（捕获阶段），
只写 `stopPropagation()` 挡不住同样挂在 window 上的 page.tsx 全局 Esc。
